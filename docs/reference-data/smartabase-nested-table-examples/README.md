# Smartabase Nested Table Examples

This folder contains non-secret CSV exports kept as reference material for future nested-table and duplicate-event work.

Files:

- `Lab Testing event form.csv`
- `Submaximal Testing event form.csv`

These examples are useful because they show event-form exports where repeated or table-like row data must be interpreted carefully. They should inform future payload grouping behavior, nested table detection, and documentation examples.

Do not add secret credentials or sensitive AMS exports here. Only reviewed, non-secret reference data should be tracked.
